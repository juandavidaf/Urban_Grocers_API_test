# Pruebas de API para la aplicación Urban Grocers
## Objetivo del proyecto
Analizar dos diferentes requisitos relacionados con la adición de productos a un kit y el cálculo del valor de la entrega en la aplicación Urban Grocers.
## Pasos para ejecutar las pruebas
1. Abrir Postman
2. Crear una variable URL en el Environment.
3. Colocar la URL proporcionada por el servidor para interactuar con la API de Urban Grocers.
4. Ejecutar cada prueba usando el método POST y el body especificado.
5. Contrastar el resultado esperado con el resultado real y realizar el informe de error, si es necesario.
